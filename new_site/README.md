# Прототип евангелизационного сайта
## "Благая весть для тех, кто ищет Бога"

---

## 📋 Описание проекта

Это простой статический прототип евангелизационного сайта, созданный согласно концепции с 7 категориями пользователей. Сайт предназначен для людей, которые ищут Бога, сомневаются в Его существовании или хотят углубить свое познание.

### 🎯 Главная цель

**Рассказать людям о Боге:**
1. Возбудить богоискание
2. Помочь в богопознании
3. Зародить веру
4. Привести к возрождению
5. Утвердить в праведности

## 🗂️ Категории пользователей

### 1. 🤔 "Я не верю в Бога или сомневаюсь"
- Творение о Боге
- Человек — образ и подобие Бога

## 🚀 Как использовать

### Локальный запуск

1. Откройте файл `index.html` в браузере
2. Или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# PHP
php -S localhost:8000
```

3. Откройте браузер: `http://localhost:8000`

## 🎨 Кастомизация

### Цветовая схема

Отредактируйте CSS переменные в `css/style.css`:

```css
:root {
  --color-primary: #2c5282;     /* Основной цвет */
  --color-secondary: #4a7ba7;   /* Вторичный цвет */
  --color-accent: #e07a5f;      /* Акцентный цвет */
  --color-text: #2d3748;        /* Цвет текста */
}
```

### Типографика

```css
:root {
  --font-primary: -apple-system, BlinkMacSystemFont, 'Segoe UI', ...;
  --font-size-base: 16px;
}
```
