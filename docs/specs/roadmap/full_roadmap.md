# Полный Roadmap — сайт «Богоузнание»

> Полный план развития сайта от MVP до зрелого проекта.

---

## 🗺️ Обзор этапов

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   ЭТАП 1: MVP   │ ──► │  ЭТАП 2: РОСТ   │ ──► │ ЭТАП 3: ЗРЕЛОСТЬ│
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

---

## 📍 ЭТАП 1: MVP

**Цель:** Запустить работающий сайт с базовым контентом.

### Контент
- [ ] Описания 7 категорий
- [ ] 14–21 материал (по 2–3 на категорию)
- [ ] 6–12 свидетельств
- [ ] Страница «О проекте»
- [ ] Ссылки на внешние ресурсы

### Разработка
- [ ] Основной сайт на Next.js
- [ ] Адаптивный дизайн (мобильные устройства)
- [ ] Форма «Просьба о молитве»
- [ ] Базовая админка для контента
- [ ] Хостинг и домен

### Результат
✅ Работающий сайт с возможностью читать материалы и отправлять молитвенные просьбы.

---

## 📍 ЭТАП 2: РОСТ

**Цель:** Расширить контент, улучшить удобство, добавить рассылку.

### Контент
- [ ] Расширение до 35–50 материалов
- [ ] Детский раздел: подборки видео и аудио
- [ ] Раздел музыки: плейлисты
- [ ] Больше свидетельств (до 20)

### Новые функции
- [ ] **Поиск** по материалам (по заголовкам и тегам)
- [ ] **Подписка на рассылку** (email)
- [ ] **Улучшенная админка:**
  - Черновики и публикация
  - Управление медиафайлами
  - Статистика просмотров

### Улучшения
- [ ] SEO-оптимизация (мета-теги, карта сайта)
- [ ] Ускорение загрузки
- [ ] Улучшение навигации

### Результат
✅ Сайт с расширенным контентом, поиском и возможностью подписки.

---

## 📍 ЭТАП 3: ЗРЕЛОСТЬ

**Цель:** Постоянное развитие и поддержка.

### Регулярная работа с контентом
- [ ] Публикация новых материалов
- [ ] Обновление существующих материалов
- [ ] Сезонные подборки (праздники, темы)
- [ ] Сбор и публикация новых свидетельств

### Расширенные функции (по необходимости)
- [ ] **Полнотекстовый поиск** (более точный)
- [ ] **Рассылки:** регулярные письма подписчикам
- [ ] **Аналитика:** отчёты о популярных материалах
- [ ] **Интеграции:** видео/аудио плееры

### Возможные дополнения (опционально)
- [ ] Личный кабинет (закладки, история)
- [ ] Онлайн-курсы / программы обучения
- [ ] Чат / консультации
- [ ] Многоязычность

## 📝 План сбора контента

### Приоритет 1 (первая очередь)

| Категория | Темы для материалов |
|-----------|---------------------|
| Сомневающиеся | Творение о Боге, Пророчества, Наука и Библия |
| Ищущие | Характер Бога, Божья любовь |
| Молодые христиане | Молитва, Чтение Библии |

### Приоритет 2 (вторая очередь)

| Категория | Темы для материалов |
|-----------|---------------------|
| Православные | Писание vs предание, Спасение по благодати |
| Евреи | Пророчества о Мессии |
| Мусульмане | Уникальность Писания |
| Ученичество | О человеке, О браке |

### Приоритет 3 (после запуска MVP)

- Свидетельства всех категорий
- Расширенные материалы
- Детские ресурсы
- Музыкальные подборки

## ✅ Чек-лист готовности к запуску MVP

**Контент:**
- [ ] Все 7 категорий имеют описания
- [ ] Минимум 2 материала в каждой категории
- [ ] Страница «О проекте» готова
- [ ] Минимум 6 свидетельств

**Техника:**
- [ ] Сайт работает на домене
- [ ] Форма молитвы отправляет уведомления
- [ ] Сайт адаптирован под телефон
- [ ] Скорость загрузки < 3 сек

**Проверка:**
- [ ] Все ссылки работают
- [ ] Тексты вычитаны
- [ ] Тестирование 3–5 людьми
