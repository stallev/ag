# app_functionality.md

## Публичный функционал (по прототипу `html_version`)
- **Главная**: выбор пути (7 карточек категорий), навигация по якорям, CTA к категориям.
- **Страницы категорий (category-1..7)**: иконка, вводный текст, список тем с CTA «Читать далее» (ведёт на шаблон поста), блок «Что дальше?» с переходом на следующую категорию или назад к выбору.
- **Пост-шаблон (`post-template.html`)**: заголовок, мета-информация (категория, теги), контентная область и блок похожих материалов, навигация к категории.
- **Страница ресурсов (`additional-functions.html`)**: карточки сервисов (библиотека, детский отдел, онлайн-трансляции, молитва, музыка, газета) с переходами на подстраницы.
- **Подстраницы ресурсов (например, `addition/library.html`)**: список разделов/тем, вводный герой-блок, цитаты/обоснования, навигация-хлебные крошки.
- **О проекте**: миссия, богословские основы, принцип постепенного откровения, аудитории, контакты.
- **Навигация**: единая шапка, хлебные крошки на внутренних страницах, подвал с ссылками на основные разделы.
- **Технические детали прототипа**: статический HTML+CSS+JS, `meta robots: noindex, nofollow`, мобильное меню на JS, без серверных форм.

## Планируемое расширение функционала (публичная часть)
- Страницы материалов с реальным контентом (тексты, медиа, встраивания видео/аудио).
- Форма «Просьба о молитве» с подтверждением/уведомлением.
- Поиск по материалам (текст, теги, категории).
- Подписка на рассылку (email).
- Личный кабинет (опционально) для сохранения закладок/избранного.

## Админка: функциональные требования
- **Роли и доступы**: Admin, Editor, Moderator; вход через Cognito; MFA по желанию.
- **Управление контентом**:
  - Категории (7 путей) и их тексты/иконки/CTA.
  - Темы внутри категорий и материалы (посты) с тегами, статусами (draft/published), датами.
  - Ресурсные карточки (библиотека, дети, трансляции, музыка, газета) и их описания/ссылки.
  - Статические страницы («О проекте», «Ресурсы») — редактируемые блоки контента.
  - Медиа-библиотека (изображения, аудио, видео) с загрузкой на S3.
- **Модерация**:
  - Очередь пользовательских обращений (молитвенные просьбы, вопросы пастору) с отметками статуса (новая/в работе/закрыта).
  - Лог действий администраторов.
- **Поиск и фильтрация**: по заголовкам, тегам, категориям, статусам материалов; полнотекстовый поиск по OpenSearch.
- **Рассылки и уведомления**: отправка писем (SendGrid) о новых запросах, подборка новых материалов подписчикам.
- **Аналитика (минимум)**: базовые метрики посещаемости и вовлечения (интеграция через CloudWatch + внешняя аналитика).

## Предлагаемые сервисы AWS (реализация)
- **Frontend**: Next.js (SSG/SSR), хостинг через AWS Amplify Hosting + CloudFront.
- **API слой**: AWS AppSync (GraphQL) + Lambda (для отдельных задач) / API Gateway (REST при необходимости).
- **Данные**: DynamoDB (материалы, категории, теги, обращения), S3 (медиа), OpenSearch (поиск).
- **Аутентификация**: Cognito User Pools + RBAC для админки.
- **Рассылки/уведомления**: SendGrid (через SSM Parameter Store для ключей) или SES для транзакционных писем.
- **IaC**: Amplify CLI (хранение конфигураций в репозитории), окружения dev/stage/prod.
