## Обзор

### Назначение административного интерфейса
Админ-панель сайта «Богоузнание» предназначена для:
- **Управления контентом** — создание, редактирование, публикация материалов
- **Модерации обращений** — обработка молитвенных просьб и вопросов
- **Управления медиа** — загрузка и организация изображений, аудио, видео
- **Аналитики** — отслеживание посещаемости и эффективности контента
- **Настроек** — конфигурация системы и управление пользователями

### Технологический стек
- **Frontend:** Next.js (React) с TypeScript
- **API:** AWS AppSync (GraphQL)
- **Аутентификация:** AWS Cognito
- **Хранилище:** DynamoDB + S3 (медиа)
- **Поиск:** OpenSearch (Post-MVP)

### Описание ролей

#### Administrator (Администратор)
- Полный доступ ко всем функциям системы
- Управление пользователями и ролями
- Системные настройки и конфигурация
- Удаление контента

#### Editor (Редактор)
- Создание и редактирование всего контента
- Загрузка медиафайлов
- Публикация материалов
- Создание рассылок (без отправки)
- Обработка обращений

#### Moderator (Модератор)
- Просмотр контента (без редактирования)
- Обработка и ответы на обращения
- Базовая модерация

## UX-паттерны интерфейса

### Общие принципы

1. **Консистентность** — одинаковые элементы управления везде
2. **Обратная связь** — toast-уведомления о действиях
3. **Подтверждение** — модалы для деструктивных операций
4. **Автосохранение** — для форм редактирования контента
5. **Отмена действий** — возможность отката изменений

```graphql
type Query {
  # Материалы
  posts(filter: PostFilter, pagination: Pagination): PostConnection
  post(id: ID!): Post
  
  # Категории
  categories: [Category!]!
  category(id: ID!): Category
  
  # Обращения
  prayerRequests(status: RequestStatus, pagination: Pagination): RequestConnection
  prayerRequest(id: ID!): PrayerRequest
  
  # Подписчики
  subscribers(status: SubscriberStatus, pagination: Pagination): SubscriberConnection
  
  # Аналитика
  analytics(period: AnalyticsPeriod): AnalyticsData
  
  # Пользователи
  users: [User!]!
  currentUser: User
}

type Mutation {
  # Материалы
  createPost(input: PostInput!): Post
  updatePost(id: ID!, input: PostInput!): Post
  deletePost(id: ID!): Boolean
  publishPost(id: ID!): Post
  
  # Обращения
  updateRequestStatus(id: ID!, status: RequestStatus!, assignee: ID): PrayerRequest

  # Рассылки
```

### Модель данных

```typescript
interface Post {
  id: string;
  slug: string;
  title: string;
  content: string;
  excerpt?: string;
  categoryId: string;
  topicId?: string;
  tags: string[];
  status: 'draft' | 'published' | 'archived';
  heroImage?: string;
  author: string;
  publishedAt?: Date;
  createdAt: Date;
  updatedAt: Date;

    title?: string;
    description?: string;

  lastLoginAt?: Date;
}
```
