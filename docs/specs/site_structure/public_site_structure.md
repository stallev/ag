## Обзор

### Цель публичной части
Публичная часть сайта «Богоузнание» предназначена для:
- **Евангелизации** — помощи людям в познании Бога
- **Обучения** — предоставления структурированных материалов о вере
- **Поддержки** — молитвенного сопровождения и пастырской заботы
- **Ресурсов** — доступа к христианской литературе, музыке и медиа

### Целевые аудитории
1. **Сомневающиеся и атеисты** — ищущие рациональные основания веры
2. **Верующие в Бога** — желающие глубже познать Его характер
3. **Представители других конфессий** — православные, католики
4. **Представители других религий** — евреи, мусульмане
5. **Молодые христиане** — нуждающиеся в основах веры
6. **Ученики Христа** — стремящиеся к систематическому обучению

## Информационная архитектура

### Принцип постепенного откровения
Структура сайта отражает богословский принцип постепенного откровения:

```
Уровень 1: Существование Бога
    ↓
Уровень 2: Характер Бога (святость, любовь, справедливость)
    ↓
Уровень 3: Путь спасения (уникальность Христа)
    ↓
Уровень 4: Жизнь во Христе (ученичество)
```

### Иерархия контента

```
Главная
├── Категории (7 путей познания)
│   ├── Темы (тематические блоки)
│   │   └── Материалы (отдельные статьи/посты)
│   └── Блок «Что дальше?» (переход к следующей категории)
├── Свидетельства
│   └── Категории свидетельств (6 типов)
│       └── Отдельные истории
├── Ресурсы
│   └── Подразделы (6 типов ресурсов)
│       └── Детальные страницы
└── О проекте
```

## Навигационная система

### Главная навигация (Header)
```
Богоузнание | Главная | Выбрать путь | Свидетельства | О проекте | Ресурсы | [☰]
```

**Поведение:**
- Desktop (≥768px): Горизонтальное меню
- Mobile (<768px): Скрытое меню с кнопкой-гамбургером

### Хлебные крошки (Breadcrumbs)
Отображаются на всех страницах кроме главной:
```
Главная > [Раздел] > [Подраздел] > [Текущая страница]
```

### Навигация в футере
```
├── Богоузнание (логотип + описание)
└── Контакты
    ├── О проекте
    ├── Ресурсы
    └── Связаться с нами
```

### Внутренняя навигация
- **На страницах категорий:** Блок «Что дальше?» с переходом на следующую категорию
- **На страницах материалов:** Блок похожих материалов + возврат к категории
- **Якорные ссылки:** На главной — скролл к секции категорий

## Пользовательские пути (User Journeys)

### Путь 1: Сомневающийся → Верующий
```
Главная
    ↓
Категория 1: "Я не верю или сомневаюсь"
    ↓
Тема: "Творение о Боге" (материал)

    ↓

    ↓

```
Главная
    ↓

    ↓
